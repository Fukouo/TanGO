# TanGO

一款面向中文使用者的 Android AI 日语词典。输入日语、中文或英语，查找日语单词与语法，查看中文释义和例句，并将需要复习的词条收藏到本地。

支持 **Android 8.0 及以上**。当前版本：**1.9.1**。

## 功能

- **多语言查词**：日语按词形、读音与近似表达查找；中文反查日语表达；英语查询优先匹配日语借词，再补充意译。
- **候选与详情分开**：每次最多显示 5 个候选，完全匹配优先。点击词条后再获取中文释义、读音、词性，以及两组日语例句与中文翻译。
- **离线收藏**：收藏后可离线查看完整详情。收藏夹支持按日语、读音或中文释义进行本地模糊搜索。
- **模型与思考强度选择**：支持 ChatGPT 套餐授权连接和兼容 OpenAI Chat Completions 的 HTTPS API，按连接与模型保存思考强度。
- **临时提档重查**：空结果时自动提高思考强度；已有候选但不满意时也可手动提高，一轮最多提高两档。
- **历史与用量**：查看最近搜索，按今天、近三天、近一周或近一个月统计本应用记录的 Token 用量。

## 开始使用

### 1. 配置连接

在底部导航中打开「连接」，选择一种连接方式。

**ChatGPT 套餐**

1. 点击 **Continue with ChatGPT**，在浏览器完成登录与授权。
2. 返回应用，点击「切换模型」选择可用模型。
3. 选择该模型支持的明确思考强度。

是否能完成授权、使用哪些模型及可用额度，取决于账号和服务端支持。套餐连接与独立 API 是两种不同的连接方式；应用不会在请求失败后自动切换到另一种计费方式。

**独立 API**

1. 展开「API Key 配置」，填写 HTTPS 基础地址和 API Key。
2. 拉取并选择模型，或手动填写服务提供的模型名称。
3. 保存并使用 API，再选择接口支持的思考强度。

这里的“兼容 OpenAI”指 **接口格式**，并不限制模型品牌。除 GPT 外，也可以配置提供相同接口的 DeepSeek、Claude 兼容层或其他模型服务。

| 服务 | 基础地址示例 | 注意事项 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | 使用对应服务的 API Key 和模型名称 |
| DeepSeek | `https://api.deepseek.com` | 提供 OpenAI 兼容接口；模型名称以服务列表为准 |
| Claude 官方兼容层 | `https://api.anthropic.com/v1` | 不是原生 Messages 接口；部分 Key 需要额外工作区请求头，当前应用尚不提供该请求头配置 |
| 其他兼容服务 | 服务提供的 HTTPS 基础地址 | 需兼容 Chat Completions 请求、响应及鉴权方式 |

独立 API 的费用由对应服务计算，不包含在 ChatGPT 套餐连接中。以上地址说明接入方式，不代表当前版本已对每家服务完成真实调用测试。

**思考强度存在服务差异。** 当前应用统一发送 `reasoning_effort`，尚未针对各供应商做专门映射。DeepSeek 的部分档位会映射到相同实际强度；Claude 官方兼容层会忽略该字段，因此界面提档不等于其实际思考强度提高。详情见 [接口兼容性](docs/DEVELOPMENT.md#接口兼容性)。

### 2. 查词与阅读

在「查词」中输入词语或表达，例如 `いる`、`たく`、`hello` 或 `没关系`。点击候选进入详情，可查看释义和例句，也可收藏到词库。

点击左上角图标或 **TanGO** 标题可返回首页；右上角显示当前模型，点击可进入连接设置。首页搜索历史默认显示最近 3 条，可展开查看。

### 3. 提高思考强度

查词从你选择的强度开始。例如基础强度为「低」时，空结果会依次尝试「中」「高」，任一档返回候选就停止自动提档。

如果候选里没有需要的词，可点击「提高一档再查」。自动与手动操作共享同一个上限：**一轮最多提高两档，最多发起 3 次查词请求**；达到模型可选的最高档时提前停止。

临时提高不会修改保存的设置，新一轮查词和详情查询仍使用基础强度。网络、鉴权、限额或参数错误不会触发自动提档。提高强度可能增加耗时和 Token 消耗，也不保证一定能找到结果。

## 数据与隐私

- API Key 和授权令牌使用 Android Keystore 加密，保存在应用私有存储中。
- 查询内容和选中的词条会发送到当前配置的 AI 服务。请仅连接你信任的服务。
- 收藏、搜索历史、缓存和用量记录保存在设备本地。卸载应用会清除本地数据。
- 查词和详情缓存按连接、模型及思考强度区分，保留 30 天、最多 300 条；命中缓存时不再请求模型。
- 用量页统计本应用在当前设备记录的请求，不等同于账号整体额度或账单。服务未返回的用量显示为「未返回」。

## 使用限制与反馈

词条由 AI 生成，可能出现遗漏、误释或不自然的例句；近似词、略语和网络用语的识别能力也取决于所选模型。重要用法建议结合上下文与可靠词典核对。

遇到问题可 [提交 Issue](https://github.com/Fukouo/TanGO/issues)，附上应用版本、Android 版本、模型名称、复现步骤，以及必要的截图。请隐去 API Key、授权令牌和个人账号信息。
