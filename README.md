# TanGO 1.9.1

基于用户确认的1.8.0查词行为增加临时提档。versionCode19，包名com.tango.nihongo，Android8及以上。安装包`dist/TanGO-1.9.1-debug.apk`与原版本同签名，版本号高于之前发布的1.8.3，可直接覆盖。

## 临时提高思考强度

- 正常查询读取本机保存的思考强度。
- 模型返回空候选时，提高到下一档再查，最多提高两档。低→中→高：一轮最多3次查词请求，任一档有候选即停止自动提档。
- 有候选但不合意时，列表下方“提高一档再查”继续同一轮；手动与自动提档共用两档上限。
- 按当前模型已配置的可选档位向上走，跳过已知不支持档位，达到最高档就停止。服务仍可能拒绝某档，此时显示错误并停止，不降档或另行重试。
- 临时档位不保存到设置。新一轮查询、详情请求仍使用原保存强度。修改输入、模型、连接或基础强度后，须点击查找开始新一轮。
- 空结果、各次提档都有按实际档位区分的缓存；缓存命中不调用模型。用量按每次实际请求分别记录。
- 离开查词页、返回首页或关闭页面后，不继续追加提档；已经发出的请求不承诺即时取消。
- 已删除“模型默认”选项。历史设置为空时显示“选择强度”，首次查词弹出明确档位选择；不擅自迁移到低或中。查词与联网详情均须明确强度。
- 限额、鉴权、网络、参数或响应格式错误不会触发提档。提档可能提高这一轮总Token消耗，具体随服务和回答变化。

## 保留的查词行为

沿用1.8.0的查词提示和详情逻辑；参数错误提示改为选择明确受支持档位。英语先日语借词，再意译；候选主词用日语、读音平假名，英语可在释义里。候选最多5个，完全匹配优先。平片假名、全半角在本地统一。不包含回退后已放弃的1.8.1/1.8.2查词扩展。

修复1.8.0中导致Android U_ILLEGAL_ARGUMENT_ERROR的假名正则，改用字符扫描。没有改变API协议或扩大原模型参数列表。

首页、模型切换、收藏搜索、紧凑收藏卡片、搜索历史、按日期用量等保持原有功能。收藏/账号存储不迁移，签名不变。

## 文件和构建

- `app/src/`：当前源码和资源。
- `scripts/build-local.ps1`：使用保留的JDK17、Android Platform35和Build Tools35.0.0打包。
- `scripts/test.ps1`、`tests/`：原规则/协议/接口模拟及新增提档检查。
- `dist/`：当前APK、源码包、构建测试日志、签名/元数据/校验和。
- `assets/branding/`：当前头像和生成说明。
- `.tools/`：本地工具、测试依赖及原签名，不纳入源码包。请保留debug.p12以便覆盖安装。
- `.rollback-backups/`：恢复版本及当前变更前的备份，不纳入源码包。

```powershell
.\scripts\test.ps1
.\scripts\build-local.ps1
```

当前本地测试和构建已通过，真机交互和真实模型尚未验收，详见`VALIDATION-1.9.1.md`。保留1.8.0回退基线，避免再次丢失恢复点。手机凭据及收藏在手机私有存储中，源码包不包含它们。
